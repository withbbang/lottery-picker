# 텔레그램 메시지 포맷

앱이 보내는 텔레그램 메시지 문구를 한곳에 모은 문서다. 문구를 바꾸려면 이 문서와 아래 "소스" 위치를 함께 고친다.

- 기준: `feat/telegram-message-format` (Task 7 이후 포맷 정리)
- 문구 소스: `apps/api/src/main/java/com/lotterypicker/notification/MessageFormatter.java`
- 고지문 소스: `RecommendationSetResponse.DISCLAIMER` (웹 추천 화면과 공유)
- 테스트: `apps/api/src/test/java/com/lotterypicker/notification/MessageFormatterTest.java`

## 공통 규칙

| 항목      | 현재 동작                                                                                          |
| --------- | -------------------------------------------------------------------------------------------------- |
| 전송 방식 | Bot API `sendMessage`, 보내기 전용                                                                 |
| 서식      | **HTML** (`parse_mode: HTML`). `<b>`, `<pre>` 등이 적용된다. 고정 문구 밖의 값에 `<` `>` `&`가 들어가면 이스케이프해야 한다 |
| 날짜      | 추천 메시지는 `2026-11-09(월)`, 실패 메시지는 `2026-11-09`                                         |
| 번호      | 오름차순, 두 자리 폭(한 자리는 앞을 공백으로), `" · "`로 구분, `<pre>` 고정폭 블록                   |
| 중복 방지 | `notification_log`의 `(kind, target_key)` 유니크. 같은 알림은 한 번만 보낸다                       |
| 실패 처리 | 5초 간격 최대 3회 시도 후 `FAILED`. 추천은 유지하고 웹 카드에 `텔레그램 발송 실패` 표시            |
| 미설정    | `TELEGRAM_BOT_TOKEN` 또는 `TELEGRAM_CHAT_ID`가 비면 보내지 않고 기록도 남기지 않음 (`SKIPPED`)     |

## 구현된 메시지

### 1. 일일 추천 — `DAILY_RECOMMENDATION`

- **언제:** 매일 17:00 추천 생성 직후. 17시에 서버가 꺼져 있었으면 기동 시 보충(판매 중일 때만, 토요일 20:00 마감)
- **중복 키:** 추천 날짜 (`2026-11-09`)
- **소스:** `MessageFormatter.recommendation(RecommendationSet)` ← `RecommendationJob.notifyRecommendation`

템플릿

```text
{날짜}({요일}) · {회차}회 추천

<pre>{번호1} · {번호2} · {번호3} · {번호4} · {번호5} · {번호6}  {전략 라벨}
… (추천 5줄, 대조군 제외)</pre>

실제 당첨 확률과 무관합니다.
```

예시 (텔레그램 화면, 번호 5줄은 고정폭)

```text
2026-11-09(월) · 1249회 추천

 3 · 11 · 19 · 27 · 38 · 44  최근 빈도
 2 ·  9 · 15 · 23 · 31 · 40  장기 미출현
 1 · 12 · 17 · 27 · 34 · 43  전체 빈도
 5 ·  8 · 21 · 26 · 33 · 45  번호 쌍
 4 · 13 · 20 · 29 · 36 · 41  균형

실제 당첨 확률과 무관합니다.
```

- 번호를 앞, 라벨을 뒤에 둔다. 한글은 고정폭 블록에서도 기기마다 폭이 달라 라벨을 앞에 두면 번호 열이 어긋난다.
- 대조군(`CONTROL`) 줄은 성적표 비교 전용이라 넣지 않는다.
- 줄별 추천 근거(웹 카드에 보이는 문구)와 완화 표시는 메시지에 넣지 않는다.

### 2. 추천 생성 실패 — `RECOMMENDATION_FAILED`

- **언제:** 17:00 생성 또는 기동 보충에서 추천 생성이 예외로 끝났을 때
- **중복 키:** 추천 날짜
- **소스:** `MessageFormatter.recommendationFailed(LocalDate)` ← `RecommendationJob.notifyFailure`

```text
{날짜}(요일) 추천 생성에 실패했습니다.
서버 로그를 확인해 주세요.
```

예시

```text
2026-11-09(월) 추천 생성에 실패했습니다.
서버 로그를 확인해 주세요.
```

## 전략 라벨

`MessageFormatter.label(StrategyType)`

| `StrategyType` | 라벨        | 메시지 포함 |
| -------------- | ----------- | ----------- |
| `RECENT_HOT`   | 최근 빈도   | O           |
| `LONG_COLD`    | 장기 미출현 | O           |
| `ALL_TIME`     | 전체 빈도   | O           |
| `PAIR`         | 번호 쌍     | O           |
| `BALANCED`     | 균형        | O           |
| `CONTROL`      | 대조군      | X (필터됨)  |

## 예정된 메시지 (Task 8, 아직 문구 없음)

`NotificationKind`에 종류만 정의돼 있고 문구는 Task 8에서 만든다. 아래는 스펙(`docs/superpowers/specs/2026-11-06-lotto-blueprint-design.md` 4장)과 플랜이 요구하는 내용이다.

| 종류                | 언제                                                                                                                                   | 중복 키     | 담아야 할 내용                                                                                       |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------- |
| `DRAW_FINISHED`     | 새 회차 당첨번호 수집 후 비교 계산이 끝났을 때 (회차당 1회). 추천이 없는 오래된 회차는 보내지 않고, 7일 이내 회차는 추천이 없어도 보냄 | 회차        | 회차, 당첨번호, 줄별 최고 등수, 등수별 줄 수, 가상 당첨금 합계. 늦게 수집됐으면 그 사실. 대조군 제외 |
| `COLLECTION_FAILED` | 일요일 12:00까지 새 회차가 수집되지 않았을 때 (1회)                                                                                    | 기대 추첨일 | 수집 지연 사실. 이후에도 1시간마다 계속 확인함                                                       |
| `COLLECTION_ERROR`  | 수집기 예외(응답 형식 변경 등)                                                                                                         | 기대 추첨일 | 수집 오류 사실. 잘못된 값은 저장하지 않음                                                            |
